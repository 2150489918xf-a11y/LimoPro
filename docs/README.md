## 新文档放在哪里

- 环境、代码说明和开发约定放在 `01-项目与开发/`。
- SSH、远程桌面、网络操作教程和故障处理放在 `02-连接与排障/`。
- 原厂手册及其阅读说明放在 `03-官方手册/`。
- 源码来源、版本和依赖采集记录放在 `04-源码与依赖/`。

新增文档后在本页补充链接和用途。文件名以主题为主；定期采集记录需要区分版本时，再在名称中附加日期。故障记录应注明是否解决及验证范围。
