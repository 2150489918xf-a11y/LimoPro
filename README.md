# 松灵 LIMO Pro 学习与巡检项目

本仓库保存 LIMO Pro 的底盘、建图导航配置和巡检示例，以及学习和故障处理文档。首次源码基线于 2026-11-24 从小车实际工作区采集，保留了所选目录中已有的修改。

## 代码目录

```text
LimoPro/
├── ros1/src/          # ROS 1 Noetic：底盘、启动配置、路径跟随和多点导航
├── ros2/src/          # ROS 2 Foxy：底盘、状态消息和 Nav2 等启动配置
├── docs/             # 手册、排查记录、源码来源和维护流程
└── scripts/          # 只读采集车端源码的工具
```

阅读代码从[底盘与导航代码索引](docs/01-项目与开发/底盘与导航代码索引.md)开始；版本维护方式见[代码维护流程](docs/01-项目与开发/代码维护流程.md)。所有文档按用途整理在[文档导航](docs/README.md)中。

这是项目核心源码的初始基线，尚未在新工作区编译或实车验收。第三方导航框架、传感器驱动、机器人模型和系统依赖未完整收录，不能仅通过 `git clone` 重建整个车端环境。来源和逐文件 SHA-256 见[源码初始基线](docs/04-源码与依赖/源码初始基线.json)，外部依赖见[外部依赖盘点](docs/04-源码与依赖/外部依赖盘点.json)。

首次入库不切换小车当前运行的工作区。源码的既有版权和许可保留在对应文件、包和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 中。

## 项目目标

以松灵 LIMO Pro 为实验平台，先熟悉小车的软硬件、开发环境和基础操作，再实现自主导航和网页控制，最终在实际场地跑通一套可重复执行的巡检流程。

最终希望能从网页选择并启动巡检任务，让小车按路线依次到达巡检点，在约定位置采集或记录数据，并在网页查看执行进度、异常和巡检结果。

## 阶段与验收

| 阶段 | 要完成的工作 | 验收标准 |
| --- | --- | --- |
| 1. 小车入门（当前） | 盘点系统、ROS 环境和传感器，学习原厂启动、状态查看和基础遥控操作 | 写出可复现的启动与停止步骤，能查看小车状态和主要传感器数据，并完成基础遥控验证 |
| 2. 自主导航 | 在选定的测试区域完成建图、地图保存、定位和目标点导航 | 重启后能加载地图，在测试区域完成定位，并自主到达预设目标点 |
| 3. 网页控制 | 开发小车控制页，查看在线状态和任务进度，支持手动控制以及导航任务的启动和停止 | 在浏览器中能查看状态、下发操作、停止任务，并确认小车是否成功执行 |
| 4. 巡检应用 | 配置巡检路线、巡检点和采集项，串联导航、数据采集、异常记录和结果查看 | 在实际场地完成一轮多点巡检，能查询各点执行结果和失败原因，并能重复执行同一路线 |

## 登录小车

在本机终端运行以下命令，连接已配置的 SSH 主机 `LimoPro`。

```sh
ssh LimoPro
```

登录菜单中输入 `1` 进入 ROS 1 Noetic 环境，输入 `2` 进入 ROS 2 Foxy 环境。

电脑和小车网线直连时，使用 `ssh agilex@192.168.137.102`。直连配置、Wi‑Fi 故障和 U 盘诊断步骤见[网络故障排查与恢复](docs/02-连接与排障/网络故障排查与恢复.md)。

## 待补充的工作空间信息

优先完成底盘、雷达和相机的运行验证，再按阶段补齐实地地图、网页接口和巡检需求。

| 优先级 | 信息 | 建议记录的内容 |
| --- | --- | --- |
| 现在 | 启动与调试 | 两套 ROS 中项目实际采用的版本、实测可复现的启动和停止步骤、基础遥控结果 |
| 现在 | 传感器与数据 | 底盘运动模式、实际发布的话题和坐标系、雷达和相机是否有有效数据 |
| 导航阶段 | 测试场地与地图 | 建图区域、地图文件位置、初始定位点、测试目标点，以及实际跑通的启动和导航步骤 |
| 网页阶段 | 控制范围与接口 | 网页运行在哪台设备、从哪里访问、需要展示的状态、允许执行的操作，以及小车端的控制接口 |
| 巡检阶段 | 巡检任务与验收 | 巡检路线和点位、每个点要采集的数据、异常判定条件、记录保存位置和验收场景 |

操作记录可按日期写下执行位置、命令、预期结果、实际结果和待解决问题，方便换环境或重启后复现。
